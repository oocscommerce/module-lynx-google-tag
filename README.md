# Lynx Google Tag

`oocscommerce/module-lynx-google-tag`

Google Analytics 4 for the Lynx storefront.

## Features

- A Google Tag component placed once per design
- Page view, purchase and seven ecommerce events, each with its own switch
- Loads lazily, so the tag does not delay the first page load

## Installation

Part of [Lynx](https://docs.oocscommerce.com/lynx/), installed with the metapackage:

```bash
composer require oocscommerce/magento2-lynx-community
```

See [Installation](https://docs.oocscommerce.com/lynx/developer/installation) for the full setup.
